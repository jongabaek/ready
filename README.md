# 월드커피포럼 2026 모바일 쇼가이드 (테스트)

`worldcoffeeforum/show.guide`를 복사해서 미니멀 디자인을 적용하고, 「내 신청」 조회·수정 기능을 붙인 테스트 버전이다.

## 구성
| 경로 | 내용 |
|---|---|
| `index.html`, `en/index.html` | 쇼가이드 (국문에만 「내 신청」 섹션 `#my`) |
| `css/style.css` | 미니멀 테마 + 내 신청 화면 스타일 |
| `js/config.js` | **API_URL** 설정 (비우면 테스트 모드) |
| `js/planner.js` | 조회 · 결과 · 수정 화면 |
| `apps-script/Code.gs`, `appsscript.json` | 통합관리시트에 붙이는 Apps Script 웹앱 |

## 테스트 모드
`API_URL`이 비어 있거나 주소 뒤에 `?mock=1`을 붙이면 예시 데이터로 동작한다.
이름 `김커피`, 번호 `010-1234-5678`로 조회한다.

## 실제 연결
1. 통합관리시트 → 확장 프로그램 → Apps Script
2. `Code.gs` 내용 붙여 넣기. 프로젝트 설정에서 시간대를 `Asia/Seoul`로 맞춘다.
3. 편집기에서 `testLookup` 실행 → 권한 허용 → 로그에 결과가 찍히는지 확인
4. 배포 → 새 배포 → 웹 앱 (실행 사용자: 나, 액세스 권한: 모든 사용자) → URL 복사
5. `js/config.js`의 `API_URL`에 붙여 넣고 커밋

## 데이터 흐름
- 조회: `(참고) MB수요조사_통합` 탭(집계 포함 Y 행) + `세션 현황` 탭(정원·단권·초청장·VIP·상태)을 읽어 세션별 확정/부분 확정/대기를 계산한다.
- 수정: `수정 응답` 탭(첫 저장 때 자동 생성)에 한 줄 추가한다. 원본·통합 탭은 건드리지 않는다.
  - 조회 결과에는 바로 반영된다.
  - **세션 현황 집계에 반영하려면 통합 탭 수식에 `수정 응답` 탭을 블록으로 추가해야 한다**(미적용).
- 순서: 같은 우선순위 안에서는 **그 세션을 처음 선택한 시각** 기준. 수정해도 원래 세션의 순번은 유지된다.
  시트의 「세션별 명단」 탭은 아직 최신 응답 시각 기준이라 순번이 조금 다를 수 있다.
- `SHOW_WAIT_RANK`(Code.gs): 기본 `false` → 「대기」만 표시. `true`면 「대기 N번」.
